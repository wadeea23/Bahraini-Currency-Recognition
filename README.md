# Bahraini Currency Recognition

## Project Overview

This project uses Deep Learning and YOLO to recognize Bahraini currency from images and live camera.

The system can detect different Bahraini banknotes and coins.

## Features

- Upload an image to recognize Bahraini currency.
- Use a live camera for real-time detection.
- Display detection results on the screen.

## Technologies Used

- Python
- YOLO26
- Streamlit
- OpenCV
- Google Colab

## Dataset

The dataset contains images of Bahraini currency collected using mobile phones and the internet.

Images were taken with different backgrounds, angles, and lighting conditions to help the model recognize currency in different situations.

## Model

The project uses a YOLO model trained to detect Bahraini currency.

The model was trained using Google Colab.

## Web Application

The application was built using Streamlit to provide a simple and user-friendly interface.

Users can upload images or use a live camera to detect Bahraini currency.

**Live Demo:** [Bahraini Currency Recognition](https://bahraini-currency-recognition-wadeea.streamlit.app/)

## Limitations

- Detection accuracy depends on image quality.
- Poor lighting may affect the results.
- Some currencies may look similar.

## Future Improvements

- Improve detection accuracy.
- Add more currency images to the dataset.
- Improve live camera detection.
